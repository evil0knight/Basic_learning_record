# 移动IP

[← 返回 MOC](MOC.md) | [← 主页](../../index.md)

---

移动站有一个永久地址（归属地址），归属代理负责管理。

当移动站漫游到外地网络时，向外地代理登记，获得一个**转交地址**（外地地址）。

## 数据转发流程

**发送给移动站：**

1. 数据报先发到移动站的永久地址
2. 归属代理截获，用**IP隧道**（IP套娃）将数据报封装后转发到转交地址
3. 外地代理解封装，通过 MAC 地址直接转发给移动站

**移动站发送数据：**

- 移动站直接发送，不需要经过归属代理转发

## 关键点

- 一个外地代理的转交地址可被多个移动站共用
- 外地代理用 MAC 地址在本地网络中转发数据帧

---

## 现实场景：4G/LTE 网络

你坐地铁时，手机从一个基站切换到另一个基站，但微信通话不会断——这就是移动 IP 机制在工作。

4G/LTE 网络中：
- **永久地址**：运营商分配给你的 IP（或者说你的手机号对应的网络标识）
- **归属代理**：运营商核心网中的 P-GW（PDN Gateway）
- **转交地址**：你接入某个基站时，该基站服务区分配的临时 IP
- **IP 隧道**：P-GW 把数据包封装后通过 GTP 隧道转发到当前基站

换基站时，手机向新基站登记新的转交地址，归属代理更新映射，数据包自动转发到新位置，上层 TCP 连接感知不到切换。
