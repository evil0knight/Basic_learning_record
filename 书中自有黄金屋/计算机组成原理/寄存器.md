# 寄存器

[← 存储器导航](./存储器.md) | [← 计算机组成原理知识地图](./MOC.md) | [← 主页](../../index.md)

## 它是什么

寄存器是最靠近 CPU 控制单元和运算单元的一层存储器。CPU 真正在执行指令时，最希望数据就在寄存器里，因为这里读写最快。

## 核心特点

- 速度最快，通常要求在半个 CPU 时钟周期内完成读写。
- 数量很少，一般只有几十到几百个。
- 单个寄存器能放的数据也不多，32 位 CPU 常见是 4 字节，64 位 CPU 常见是 8 字节。

## 为什么它这么重要

CPU 执行一条指令时，不只是做加减乘除，还要取指、译码、控制执行。如果寄存器访问慢，整条指令的节奏都会被拖慢，所以寄存器虽然小，却是整台机器里最“值钱”的位置之一。
