## 任务的插入

**双向链表**,就绪任务按优先级挂到就绪链表 `pxReadyTasksLists[]` 上，调度器从链表里挑最高优先级任务运行(调度看下面的)

```
就绪链表 List_t
  └─ xListEnd（哨兵） ⇄ xStateListItem（任务A）
                       ⇄ xStateListItem（任务B）
                              │ pvOwner 指向
                              ▼
                          TCB（任务B）
                              ├─ pxTopOfStack → 栈顶（保存的 16 个寄存器现场）
                              └─ pxStack      → 栈底（任务栈起始地址）
```

- `pvOwner` 是**从链表节点找回 TCB** 的桥梁：链表里存的是 `xStateListItem` 节点，调度器通过 `pvOwner` 拿到任务本体，再取 `pxTopOfStack` 恢复现场。
- 一个任务有**两个链表项**：`xStateListItem` 管「就绪/阻塞」状态，`xEventListItem` 管「等队列/信号量」事件，让任务能同时挂在两个链表上。
- `pxTopOfStack`（栈顶）和 `pxStack`（栈底）一高一低框出整个任务栈，切换任务时从 `pxTopOfStack` 恢复现场。

## 任务的调度

任务切换:

1. **taskYIELD()** :`PendSV`的悬起位置1

   `PendSV`和 `SysTick`(心跳)都设置成最低优先级,因为不能打断其他的中断
2. **PendSV**:调用 `xPortPendSVHandler`
3. **xPortPendSVHandler :** 现在的任务即将结束,把[cpu通用寄存器组](../../术中自有万钟粟/Cortex-M4内核原理/cpu通用寄存器组.md)和[特殊寄存器](../../术中自有万钟粟/Cortex-M4内核原理/特殊寄存器.md)的值进栈中(硬件自动+软件手动)

   调用 `vTaskSwitchContext()`，从就绪链表中找出下一个最高优先级的任务，更新全局指针 `pxCurrentTCB` 指向新任务。

   通过 `pxCurrentTCB`获取栈顶指针,恢复通用寄存器组和特殊寄存器,更新到PSP实现无感切换
4. 

```asm
xPortPendSVHandler
    extern pxCurrentTCB       ; 当前任务 TCB 指针
    extern vTaskSwitchContext ; C 语言调度函数

    mrs r0, psp               ; ① 取当前任务栈指针 PSP（任务专用栈）
    isb

    ldr r3, =pxCurrentTCB     ; 取 pxCurrentTCB 变量的地址
    ldr r2, [r3]              ; 取它的值 = 当前 TCB 指针

    stmdb r0!, {r4-r11}       ; ② 手动把 R4-R11 压入任务栈
    str r0, [r2]              ;    新栈顶写回 TCB->pxTopOfStack

    stmdb sp!, {r3, r14}      ; 保护 R3、R14（马上调 C 函数会被破坏）
    mov r0, #configMAX_SYSCALL_INTERRUPT_PRIORITY
    msr basepri, r0           ; 屏蔽低优先级中断
    bl vTaskSwitchContext     ; ③ 选最高优先级任务，更新 pxCurrentTCB
    mov r0, #0
    msr basepri, r0           ; 开中断
    ldmia sp!, {r3, r14}      ; 恢复 R3、R14

    ldr r1, [r3]              ; 重新取 pxCurrentTCB（已指向新任务）
    ldr r0, [r1]              ; 取新任务栈顶

    ldmia r0!, {r4-r11}       ; ④ 手动弹回 R4-R11
    msr psp, r0               ;    PSP 指向新任务栈
    bx r14                    ; 异常返回，硬件自动弹异常帧
```
