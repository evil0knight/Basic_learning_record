# 临界段保护

[← FreeRTOS内核实现与应用开发实战指南](./MOC.md)

---

临界段 = 不能被中断打断的代码区。FreeRTOS 靠抬高 [BASEPRI寄存器](../../术中自有万钟粟/Cortex-M4内核原理/特殊寄存器.md) 实现：BASEPRI 写 `configMAX_SYSCALL_INTERRUPT_PRIORITY` 后，所有「优先级数值 ≥ 该值」的中断全被屏蔽（NMI、HardFault 和优先级更高的中断仍能进来）。

| 场景 | 函数/宏 | 保存旧 BASEPRI? | 嵌套计数? | 位置 |
| --- | --- | --- | --- | --- |
| 关中断 | `portDISABLE_INTERRUPTS()` | ❌ | ❌ | portmacro.h |
| 关中断(带返回值) | `portSET_INTERRUPT_MASK_FROM_ISR()` | ✅ | ❌ | portmacro.h |
| 进临界段 | `taskENTER_CRITICAL()` | ❌ | ✅ | port.c |
| 进临界段(ISR) | `taskENTER_CRITICAL_FROM_ISR()` | ✅ | ❌ | task.h |

---

## ① 普通关中断 — portmacro.h

任务上下文里关中断前 BASEPRI 必为 0，所以不用保存旧值，直接写死门槛：

```c
static portFORCE_INLINE void vPortRaiseBASEPRI( void )
{
    uint32_t ulNewBASEPRI = configMAX_SYSCALL_INTERRUPT_PRIORITY;

    __asm
    {
        msr basepri, ulNewBASEPRI   ; 抬高 BASEPRI，屏蔽低优先级中断
        dsb
        isb
    }
}
#define portDISABLE_INTERRUPTS()    vPortRaiseBASEPRI()

/* 开中断：BASEPRI 写 0，全部放行 */
static portFORCE_INLINE void vPortSetBASEPRI( uint32_t ulBASEPRI )
{
    __asm
    {
        msr basepri, ulBASEPRI
    }
}
#define portENABLE_INTERRUPTS()     vPortSetBASEPRI( 0 )
```

## ② 带返回值的关中断 — portmacro.h

中断里 BASEPRI 可能已被别处改过（不是 0），直接写死会破坏现场。所以先 `mrs` 读出旧值、返回给调用者，退出时再恢复：

```c
static portFORCE_INLINE uint32_t ulPortRaiseBASEPRI( void )
{
    uint32_t ulReturn, ulNewBASEPRI = configMAX_SYSCALL_INTERRUPT_PRIORITY;

    __asm
    {
        mrs ulReturn, basepri        ; ① 先读旧 BASEPRI
        msr basepri, ulNewBASEPRI    ; ② 再写新值
        dsb
        isb
    }

    return ulReturn;                 ; ③ 旧值交给调用者保存
}
#define portSET_INTERRUPT_MASK_FROM_ISR()       ulPortRaiseBASEPRI()
#define portCLEAR_INTERRUPT_MASK_FROM_ISR( x )  vPortSetBASEPRI( x )
```

## ③ 进临界段 — port.c（带嵌套计数）

任务上下文用 `taskENTER_CRITICAL()`/`taskEXIT_CRITICAL()`（宏链：`taskENTER_CRITICAL` → `portENTER_CRITICAL` → `vPortEnterCritical`）。嵌套计数保证「多次进入、只在最外层退出时开一次中断」：

```c
/* 故意给非法初值：没进就退，计数变成 0xaaaaaaa9，configASSERT 必抓 */
static UBaseType_t uxCriticalNesting = 0xaaaaaaaa;

void vPortEnterCritical( void )
{
    portDISABLE_INTERRUPTS();
    uxCriticalNesting++;

    /* 只在嵌套计数 == 1 时断言：防止断言函数自身进临界段导致递归误报 */
    if( uxCriticalNesting == 1 )
    {
        configASSERT( ( portNVIC_INT_CTRL_REG & portVECTACTIVE_MASK ) == 0 );
    }
}

void vPortExitCritical( void )
{
    configASSERT( uxCriticalNesting );
    uxCriticalNesting--;

    if( uxCriticalNesting == 0 )
    {
        portENABLE_INTERRUPTS();
    }
}
```

## ④ 中断保护版本进临界段

中断里不能用带嵌套计数的版本（会破坏别处中断现场），改成「定义变量接住旧 BASEPRI，退出时用旧值恢复」：

```c
/* task.h 里的映射 */
#define taskENTER_CRITICAL_FROM_ISR()      portSET_INTERRUPT_MASK_FROM_ISR()
#define taskEXIT_CRITICAL_FROM_ISR( x )    portCLEAR_INTERRUPT_MASK_FROM_ISR( x )
```

```c
/* 中断里的用法 */
UBaseType_t uxSavedInterruptStatus;

uxSavedInterruptStatus = taskENTER_CRITICAL_FROM_ISR();  /* 关中断 + 存旧 BASEPRI */
{
    /* 临界区代码：访问与任务共享的数据 */
}
taskEXIT_CRITICAL_FROM_ISR( uxSavedInterruptStatus );    /* 用旧值恢复 */
```
