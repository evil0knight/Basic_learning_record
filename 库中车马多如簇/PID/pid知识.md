## 位置式 vs 增量式

调用方式完全一致:`pid_calc(target, measure, &u)`,只在 `e_type` 字段选择。

**位置式 `PID_POSITION`**

- 输出含义:`u = Kp·e + ∑Ki·e·dt + Kd·de/dt`
- 积分形式:显式累加,支持积分限幅
- 抗饱和:条件积分 + 可选饱和反馈接口
- 死区行为:输出零,积分保留
- 适用:角度/位置环;执行器失电后恢复更友好

**增量式 `PID_INCREMENT`**

- 输出含义:`u(k) = u(k-1) + Δu`,内部累加
- 积分形式:单周期分量,不显式累加
- 抗饱和:输出限幅即自动抗饱和
- 死区行为:Δu = 0,输出保持
- 适用:转速环;切换目标时平滑过渡

## 常用改进功能

PID 基础公式有若干工程缺陷(积分发散、微分放大噪声、目标阶跃冲击等),实际使用时按需启用下面的改进。

### 积分类

| 功能     | 解决什么问题                        | 做法                                              | 本库字段                  |
| -------- | ----------------------------------- | ------------------------------------------------- | ------------------------- |
| 梯形积分 | 矩形积分在误差变化快时偏差大        | 本次与上次误差取平均再乘`ki·dt`                | `b_trapezoid_i`         |
| 积分限幅 | 积分无节制累加导致 Windup           | 积分值限制在`±int_max`                         | `f_int_max`             |
| 条件积分 | 输出饱和时积分还在涨,恢复后反向超调 | 候选输出已超限且本次积分同向时,本次不累加         | `f_out_max`(自动)       |
| 饱和反馈 | 执行器实际给的比 PID 要的小         | 把"实际/请求"比例喂回,同向饱和时回退本次积分      | `pid_sat_feedback`      |
| 积分分离 | 大误差时积分涨太快,引起大超调       | 误差绝对值超阈值时本次不积分,靠近目标才开始积     | `f_i_sep_err`           |
| 变速积分 | 想在不同误差区段用不同积分强度      | 同向且误差超阈值时,按过渡宽度线性衰减本次积分增量 | `f_vsi_a` + `f_vsi_b` |

**Windup**:控制系统术语,指积分一直累加导致系统响应变差的现象。抗饱和(anti-windup)就是解决这个。

### 微分类

| 功能     | 解决什么问题                   | 做法                                       | 本库字段           |
| -------- | ------------------------------ | ------------------------------------------ | ------------------ |
| 微分先行 | 目标阶跃让微分瞬间产生巨大冲击 | 微分作用于测量而非误差(目标阶跃不影响微分) | `b_d_on_measure` |
| 微分滤波 | 微分天然放大噪声               | 对微分输出做一阶低通                       | `f_d_rc`         |

### 比例类

| 功能     | 解决什么问题             | 做法                                            | 本库字段           |
| -------- | ------------------------ | ----------------------------------------------- | ------------------ |
| 比例先行 | 目标阶跃让比例项瞬间冲击 | 比例项累加`-Kp·Δmeasure`,不直接响应目标变化 | `b_p_on_measure` |

### 输出类

| 功能     | 解决什么问题                      | 做法                                          | 本库字段            |
| -------- | --------------------------------- | --------------------------------------------- | ------------------- |
| 死区     | 稳态时测量噪声让输出来回抖        | 误差绝对值小于阈值时输出 0,积分保持           | `f_dead_band`     |
| 输出滤波 | 高频抖动传到执行器                | 对总输出做一阶低通                            | `f_out_rc`        |
| 堵转检测 | 执行器卡住,PID 持续满输出但无变化 | 输出高 + 相对误差大 + 持续计数达阈值,置标志位 | `u32_stall_count` |
