## 一、开环FOC控制概述

开环FOC（Field-Oriented Control，磁场定向控制）是学习FOC算法的第一步。它 不依赖电机转子位置传感器（如编码器、霍尔）和电流反馈 ，仅通过预设的电压矢量，驱动电机旋转。核心目的是验证坐标变换链（Clark/Park）与SVPWM（空间矢量脉宽调制）模块的正确性，为闭环控制打下坚实基础。
**学习目标：**掌握开环FOC的基本原理与实现步骤，能够通过代码生成旋转电压矢量，观察电机平稳启动与运行，并理解各坐标系下的信号波形。

### 核心模块说明

- 角度给定 ：手动生成一个随时间线性增长的角度值 $\theta = \omega t$，模拟转子的旋转磁场角度。
- 逆Park变换 ：将旋转坐标系下的电压指令 ($V_d$, $V_q$) 转换到静止两相$\alpha$-$\beta$坐标系。
- SVPWM模块 ：将 ($V_\alpha$, $V_\beta$) 电压矢量转换为三相逆变器的六路PWM占空比信号，实现圆形旋转磁场。
- 三相逆变器 ：通常为MOSFET或IGBT桥，根据PWM信号输出三相正弦电压。
- 电机 ：永磁同步电机（PMSM）或无刷直流电机（BLDC），在旋转磁场作用下开始转动。

## 三、实现步骤详解
1
### 初始化参数

设置电机极对数、目标电压$V_q$、频率（转速）等。$V_d$通常设为0，使磁场与转子垂直（转矩最大）。
2
### 生成角度θ

在定时中断中，累加角度：$\theta \mathrel{+}= 2\pi f \Delta t$。其中$f$为电频率，$\Delta t$为中断周期。
3
### 执行逆Park变换

使用公式：$V_\alpha = V_d \cos\theta - V_q \sin\theta$; $V_\beta = V_d \sin\theta + V_q \cos\theta$。得到静止坐标系电压矢量。
4
### 运行SVPWM算法

根据$V_\alpha$, $V_\beta$计算扇区，并计算相邻基本矢量的作用时间，生成三相占空比。
5
### 更新PWM输出

将占空比写入定时器的比较寄存器，驱动逆变器功率管。
6
### 观测与验证

使用示波器观察相电流波形（应为正弦）或电机平稳旋转，验证算法正确性。

 * 开环FOC控制主函数（在定时中断中调用，例如10kHz）
 * 假设：Vd = 0, Vq = 预设电压值

    static float theta = 0.0f; // 电角度
    float Vd = 0.0f;           // d轴电压，通常设为0
    float Vq = 1.5f;           // q轴电压，控制转矩（开环下为固定值）
    float Valpha, Vbeta;       // α-β轴电压

    // 1. 更新电角度（开环速度：speed_rps 电频率）
    theta += 2 * PI * SPEED_SET_RPS * TS;
    if (theta > 2 * PI) theta -= 2 * PI;

    // 2. 逆Park变换 (dq -> αβ)

    SVPWM_Calc(Valpha, Vbeta);

## 五、预期波形与验证要点

| 观测点 | 预期波形 | 验证目的 |
| --- | --- | --- |
| 三相相电流 ($I_u$, $I_v$, $I_w$) | 相位差120°的正弦波 | 验证SVPWM生成的三相电压平衡，电机磁场圆形旋转。 |
| $\alpha$-$\beta$轴电压 ($V_\alpha$, $V_\beta$) | 相位差90°的正弦波 | 验证逆Park变换正确，生成正交电压分量。 |
| 电机转速 | 平稳上升至稳定值 | 验证开环驱动能使电机正常启动并运行。 |
| PWM占空比波形 | 正弦调制后的脉宽波形 | 验证SVPWM算法正确调制。 |
**调试技巧：**初次运行时，建议先将目标电压$V_q$和频率设小，观察电机是否缓慢平稳转动。若电机抖动或异响，应检查SVPWM死区时间设置、电机参数（极对数）或坐标变换的正负号。
## 六、开环FOC的局限性与意义

- 局限性 ： 无法应对负载变化，负载增加时易失步。 启动特性可能不佳，需小心选择启动电压/频率。 无法实现精确的速度与位置控制。
- 学习意义 ： 理解FOC的完整信号链，隔离传感器故障影响。 验证硬件（驱动板、ADC、PWM）是否工作正常。 为后续加入电流环（电流反馈）和速度环（位置反馈）奠定基础。

开环FOC是通往高性能电机控制的必经之路。通过本讲实践，学员应能亲手让电机“转起来”，并深刻理解磁场定向的核心思想—— 将三相交流解耦为独立的转矩与磁场分量 。
