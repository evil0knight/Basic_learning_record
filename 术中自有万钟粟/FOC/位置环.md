# 位置环

[← 返回 FOC MOC](./MOC.md) | [← 返回主页](../../index.md)

---

* **输入:** 目标位置 **$\theta^*$**、反馈位置 **$\theta$**(编码器/旋变/观测器)
* **处理:** 位置误差经 P 或 PID 调节,输出速度指令
* **输出:** 速度环的参考速度 **$\omega^*$**(含速度限幅)

## 三环中的位置

位置环处在三环最外层:

```
θ* → [位置环 P/PID] → ω* → [速度环 PI] → iq* → [电流环 PI] → vd/vq → SVPWM
                       ↑                       ↑                     ↑
                     ω反馈                   iq反馈                 相电流
```

位置环只负责「误差 → 速度指令」,其他全部交给内环。

## 要点

- **带宽选择**:位置环带宽取速度环的 **1/5 ~ 1/10**,外环永远比内环慢
- **积分慎用**:P 控制通常够用;加 I 容易超调,先把 P 调到位再考虑是否加 I
- **微分先行**(`b_d_on_measure = true`):阶跃指令下只对测量值微分,避免对指令跳变求导产生的冲击
- **微分低通**(`f_d_rc`):编码器反馈必带量化噪声,微分前必须低通,否则噪声被 Kd 放大成灾
- **`f_out_max` 填速度环的最大参考速度**,保护速度环不被打爆
- **指令规划**:上位机的位置指令不要直接给阶跃,先走梯形/S 曲线平滑一遍再喂进来(规划器放在位置环之外)
- **先调电流环 → 再调速度环 → 最后调位置环**,从内到外
