# 速度环

[← 返回 FOC MOC](./MOC.md) | [← 返回主页](../../index.md)

---

* **输入:** 目标速度 **$\omega^*$**(位置环输出或上位机直给)、反馈速度 **$\omega$**(编码器差分 / PLL 观测)
* **处理:** 速度误差经 PI 调节(可选变速积分抗饱和)
* **输出:** q 轴电流指令 **$i_q^*$**(含电流限幅)

## 三环中的位置

速度环处在位置环和电流环之间:

```
θ* → [位置环] → ω* → [速度环 PI] → iq* → [电流环 PI] → vd/vq → SVPWM
                       ↑                       ↑
                     ω反馈                   iq反馈
```

速度环只负责「速度误差 → 转矩电流指令」,具体怎么把 iq 变成电压交给电流环。

## 要点

- **带宽选择**:速度环带宽取电流环的 **1/5 ~ 1/10**,通常 5~50 Hz,高性能伺服可到 100 Hz 以上;要避开机械谐振
- **初值估算**:$K_p \approx \dfrac{\omega_c J}{1.5 K_t}$,$K_i \approx \dfrac{K_p \omega_c}{5}$,仅作起步,实测必须微调
- **一般只做 PI 不加 D**:速度反馈由编码器差分或观测器给出,本身噪声大,D 会放大
- **抗积分饱和必装**:电机启停/堵转时误差大且持续,积分会炸。库里提供三条路线:
  - 简单可靠 → `f_int_max` 积分限幅
  - 不同误差区段用不同强度积分 → `f_vsi_a / f_vsi_b` 变速积分(推荐)
  - 真实饱和缩放反馈 → `pid_sat_feedback`(电流环已经做了圆限幅时用)
- **`f_out_max` 填 `I_q_max`**,直接等于你允许电机输出的最大 q 轴电流
- **反馈信号先滤波**:编码器差分出来的速度毛刺大,进 PI 前先低通一刀,避免直接触发比例项抖动
- **先把电流环调稳**:外环的所有整定都建立在内环已经收敛的前提上
