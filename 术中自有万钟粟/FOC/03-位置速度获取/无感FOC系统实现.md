## 一、核心概念与挑战

无位置传感器FOC（Sensorless FOC）通过算法估算转子位置和速度，省去了物理传感器（如编码器、霍尔），降低了成本与系统复杂度，但带来了新的技术挑战。
**三大核心挑战：**
1. 位置/速度估算精度： 在低速、零速及动态工况下保持准确估算。
1. 系统稳定性： 观测器与控制器之间的耦合可能引发振荡。
1. 启动与低速运行： 无初始位置信息下的可靠启动与低速平稳运行。

## 二、系统总体架构

一个完整的无传感器FOC系统由 状态观测器 、 锁相环(PLL) 和 双环控制器 三大部分紧密耦合而成。

### 软件架构图 (SVG示意图)

数据流说明： 电流采样后，经观测器估算反电动势（EMF），PLL从EMF中提取平滑的位置($\theta$)与速度($\omega$)信号，送入双环控制器生成电压指令，最终通过逆变换产生PWM驱动电机。

## 三、关键技术模块详解

### 1. 状态观测器（核心估算器）

观测器基于电机数学模型，利用可测量的电压、电流，估算出不可直接测量的反电动势（EMF），进而推导出转子位置。

| 观测器类型 | 原理 | 优点 | 适用场景 |
| --- | --- | --- | --- |
| 滑模观测器(SMO) | 利用开关函数迫使系统状态“滑动”到预设滑模面，对参数变化鲁棒性强。 | 鲁棒性好，计算量适中 | 中高速运行，对抖动不敏感的应用 |
| 龙伯格观测器(Luenberger) | 基于状态空间模型，通过误差反馈校正估算值。 | 估算平滑，理论成熟 | 需要平滑估算，参数已知度高的场合 |
| 模型参考自适应(MRAS) | 构建参考模型与可调模型，通过自适应律调节可调模型参数。 | 可在线辨识参数 | 参数可能缓慢变化的场合 |

#### 滑模观测器(SMO)核心代码示例 (C语言风格)

```c
// 滑模观测器核心计算函数
void SMO_Update(float I_alpha, float I_beta, float V_alpha, float V_beta, float* E_alpha, float* E_beta) {
    // 电机参数
    static float R = 1.2;   // 定子电阻 (Ω)
    static float L = 0.005; // 定子电感 (H)
    static float K = 50.0;  // 滑模增益

    // 电流估算误差
    float I_alpha_err = I_alpha_hat - I_alpha;
    float I_beta_err = I_beta_hat - I_beta;

    // 滑模控制函数 (sign函数)
    float Z_alpha = (I_alpha_err > 0) ? K : -K;
    float Z_beta = (I_beta_err > 0) ? K : -K;

    // 反电动势(EMF)估算 (核心方程)
    *E_alpha = V_alpha - R*I_alpha - L*I_alpha_dot + Z_alpha;
    *E_beta = V_beta - R*I_beta - L*I_beta_dot + Z_beta;

    // 更新电流估算状态 (使用欧拉积分)
    I_alpha_hat += Ts * (V_alpha - R*I_alpha - *E_alpha) / L;
    I_beta_hat += Ts * (V_beta - R*I_beta - *E_beta) / L;
}
```

### 2. 锁相环(PLL) - 位置/速度提取器

PLL用于从观测器输出的、含有噪声或畸变的EMF信号中，提取出平滑、连续的位置角θ和速度ω。

### 3. 双环控制器整合

将PLL输出的θ与ω，作为反馈量接入标准的FOC双环控制回路。

- 外环（速度环）： 接收速度指令ω_ref与PLL估算的ω_fbk，通过PI控制器输出电流指令Iq_ref。
- 内环（电流环）： 接收 $I_{d\_ref}$(通常为0)与 $I_{q\_ref}$，以及反馈的 $I_d$/$I_q$（经Park变换），通过PI控制器输出 $V_d$/$V_q$。
- 关键点： 使用 估算的 $\theta$ 进行Park变换（电流）和逆Park变换（电压），完成整个磁场定向控制。

## 四、实现步骤与调试要点

1. 步骤1：搭建基础FOC框架 - 先实现有传感器FOC，确保电流环、变换等基础功能正确。
1. 步骤2：集成与调试观测器 - 在开环（给定θ）下验证观测器能正确输出EMF，注意增益调节以避免振荡。
1. 步骤3：集成PLL - 将观测器EMF接入PLL，验证能输出平滑的θ与ω，调节PLL带宽（PI参数）以平衡响应速度与滤波效果。
1. 步骤4：闭环切换 - 在低速或中速下，将控制器的反馈θ从“给定值”切换到“PLL估算值”，实现闭环无传感器运行。
1. 步骤5：启动策略实现 - 实现例如“I-F启动”（电流-频率控制）或“对齐+开环启动”等策略，将电机从静止拖入观测器可工作的速度范围。
1. 步骤6：全速域优化 - 调试低速性能，可能需引入高频注入法；优化中高速观测器参数，确保动态响应与稳定性。
**调试口诀：**“先开环，后闭环；先中速，后低速；先观测，后控制；参数调节步步为营。”
## 五、关键参数整定参考表

| 模块 | 参数 | 整定方法 | 影响 |
| --- | --- | --- | --- |
| 滑模观测器 | 滑模增益 K | 由大到小调节，至系统稳定无高频抖振 | 过大导致抖振，过小导致估算滞后 |
| 滤波器截止频率 | 通常设为基波频率的5-10倍 | 影响EMF信号平滑度与相位延迟 |  |
| 锁相环(PLL) | 比例增益 Kp | 决定跟踪速度，响应变快但可能超调 | 影响速度动态响应 |
| 积分增益 Ki | 消除稳态相位误差 | 过大引起低频振荡 |  |
| 双环PI | 电流环带宽 | 通常设为1/10 ~ 1/5 PWM频率 | 影响电流跟踪速度与抗扰性 |
| 速度环带宽 | 远低于电流环带宽 (5~20倍关系) | 影响速度响应与系统稳定性 |  |
