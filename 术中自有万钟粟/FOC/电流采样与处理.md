## 一、引言：为什么电流采样至关重要？

在无刷电机磁场定向控制（FOC）中， 精确的相电流信息是矢量控制的基础 。我们需要将测得的相电流（$I_a$, $I_b$, $I_c$）通过 Clarke 和 Park 变换，转换为旋转坐标系下的直轴电流 $I_d$ 和交轴电流 $I_q$。$I_d$ 和 $I_q$ 分别对应电机的励磁分量和转矩分量，是电流环PI控制器的反馈输入。因此， 采样精度、实时性和抗噪声能力 直接决定了整个控制系统的性能、效率与稳定性。

## 二、相电流采样方法

根据在电路中放置采样电阻的数量和位置，主要分为三种方法。
1. 单电阻采样
原理： 在逆变器下桥臂的直流母线负端（GND）与电源地之间，串联一个采样电阻。通过测量该电阻两端的电压，来反推三相电流。

关键： 需要在一个PWM周期内， 选择特定的“有效矢量”时间段 进行采样，此时被测相的下桥臂导通，电流流经采样电阻，电压与相电流成正比。通常需要复杂的采样时序控制。

优点： 成本最低，仅需一个采样电阻和一套运放电路。

缺点： 采样窗口窄，对PWM时序和ADC触发要求极高；在低占空比时可能无法采样；软件算法复杂。
2. 双电阻采样
原理： 在两相的下桥臂（通常为A相和B相）与地之间，各放置一个采样电阻。通过测量这两个电阻的电压，结合三相电流之和为零（$I_a + I_b + I_c = 0$）的原理，计算出第三相电流。

关键： 采样时机相对灵活，只要被测相的下桥臂导通即可。通常能覆盖更宽的调制范围。

优点： 成本适中，采样窗口比单电阻宽，软件复杂度中等，是折中且常用的方案。

缺点： 仍存在部分PWM模式下的采样盲区，需要合理选择采样相。
3. 三电阻采样
原理： 在每一相的下桥臂与地之间都放置一个采样电阻。可以同时或分时采样三相电流。

关键： 采样时机最灵活，可以在任意时刻对任意导通的下桥臂进行采样，甚至可以采用同步采样技术。

优点： 采样精度高，无盲区，对PWM模式没有限制，软件实现相对简单，可靠性最高。

缺点： 成本最高，需要三套采样运放电路，占用更多的ADC通道。

### 三种采样方法对比

| 对比项 | 单电阻采样 | 双电阻采样 | 三电阻采样 |
| --- | --- | --- | --- |
| 硬件成本 | 最低 | 中等 | 最高 |
| 采样精度 | 较低（易受噪声干扰） | 中等 | 最高 |
| 软件复杂度 | 最高（时序苛刻） | 中等 | 最低 |
| PWM调制范围 | 受限（低占空比难采样） | 较宽 | 全覆盖 |
| 适用场景 | 成本敏感的中低速应用 | 通用型FOC控制器 | 高性能伺服、精密控制 |

## 三、ADC采样技术要点

### 1. ADC配置

- 分辨率： 通常选择12位ADC。对于高精度场合，可使用16位ADC或过采样技术。
- 采样速率： 必须远高于PWM频率。若PWM为20kHz，ADC采样转换时间应小于1us。
- 触发源： 使用定时器（如TIM1）的触发输出（TRGO）来同步触发ADC采样，确保在PWM周期内的精确时刻采样。
- 对齐方式： 数据通常右对齐，方便处理。

```c
// 示例：STM32 HAL库 ADC触发采样配置片段
void ADC_Config(void) {
    ADC_ChannelConfTypeDef sConfig = {0};
    hadc1.Instance = ADC1;
    hadc1.Init.ClockPrescaler = ADC_CLOCK_SYNC_PCLK_DIV4;
    hadc1.Init.Resolution = ADC_RESOLUTION_12B;
    hadc1.Init.ScanConvMode = ENABLE; // 扫描模式
    hadc1.Init.ContinuousConvMode = DISABLE; // 非连续，由触发启动
    hadc1.Init.DiscontinuousConvMode = DISABLE;
    hadc1.Init.ExternalTrigConv = ADC_EXTERNALTRIGCONV_T1_TRGO; // TIM1触发
    hadc1.Init.ExternalTrigConvEdge = ADC_EXTERNALTRIGCONVEDGE_RISING;
    hadc1.Init.DataAlign = ADC_DATAALIGN_RIGHT;
    HAL_ADC_Init(&hadc1);

    // 配置采样通道
    sConfig.Channel = ADC_CHANNEL_1; // 对应Ia
    sConfig.Rank = 1;
    sConfig.SamplingTime = ADC_SAMPLETIME_15CYCLES;
    HAL_ADC_ConfigChannel(&hadc1, &sConfig);
    // ... 配置其他通道
}
```

### 2. 采样时序

以单电阻采样为例，必须在有效的“采样窗口”内触发ADC。这通常发生在PWM周期中间的“有效矢量”时段。

## 四、采样数据处理与滤波

ADC采样的原始数据含有噪声，必须经过处理才能用于控制。

### 1. 数据预处理

- 偏移校准： 在电机静止时，采样ADC值作为零漂偏移量（$V_{\text{offset}}$），后续采样值减去此偏移。
- 数值转换： 将ADC值转换为实际电流值（安培）。 公式：

$$I = \frac{(\text{ADC\_Value} - \text{ADC\_Offset}) \cdot V_{\text{ref}}}{\text{ADC\_Resolution} \cdot \text{Gain} \cdot R_{\text{shunt}}}$$

```c
// 电流值转换示例代码
#define ADC_REF_VOLTAGE    3.3f
#define ADC_RESOLUTION     4096.0f // 12位
#define AMP_GAIN           20.0f   // 运放增益
#define SHUNT_RESISTANCE   0.001f  // 1毫欧

float ConvertToAmps(int16_t adc_raw, int16_t adc_offset) {
    float voltage = (adc_raw - adc_offset) * (ADC_REF_VOLTAGE / ADC_RESOLUTION);
    float current = voltage / (AMP_GAIN * SHUNT_RESISTANCE);
    return current;
}
```

### 2. 数字滤波

为了抑制开关噪声和随机干扰，必须采用数字滤波器。

| 滤波器类型 | 原理 | 优点 | 缺点 | 适用场景 |
| --- | --- | --- | --- | --- |
| 一阶低通滤波 (LPF) | $Y_n = \alpha X_n + (1-\alpha) Y_{n-1}$ | 简单，计算量小 | 引入相位滞后 | 一般噪声滤除 |
| 滑动平均滤波 | $Y_n = \frac{X_n + X_{n-1} + \cdots + X_{n-N+1}}{N}$ | 对周期性干扰有效 | 实时性稍差，占用内存 | 信号平滑 |
| 中值滤波 | 取连续$N$个采样值的中位数 | 能有效滤除脉冲干扰 | 计算量较大 | 存在偶发尖峰噪声时 |

```c
// 一阶低通滤波器实现
typedef struct {
    float alpha; // 滤波系数 (0~1)，越小滤波越强，滞后越大
    float out;   // 上一次输出
} LPF_1st;

void LPF_1st_Init(LPF_1st* lpf, float alpha, float init_val) {
    lpf->alpha = alpha;
    lpf->out = init_val;
}

float LPF_1st_Update(LPF_1st* lpf, float in) {
    lpf->out = lpf->alpha * in + (1.0f - lpf->alpha) * lpf->out;
    return lpf->out;
}

// 在电流环中调用
LPF_1st lpf_iq, lpf_id;
// ... 初始化
float iq_filtered = LPF_1st_Update(&lpf_iq, iq_raw);
float id_filtered = LPF_1st_Update(&lpf_id, id_raw);
```

滤波建议： 电流环带宽通常较高（几百Hz到几kHz），滤波器的截止频率应设置为电流环带宽的3-5倍以上，以避免影响动态响应。通常$\alpha$取值在0.2到0.5之间进行调试。

## 五、总结与最佳实践

1. 方案选择： 通用产品推荐双电阻方案，平衡成本与性能；极致成本选单电阻；高性能选三电阻。
1. 硬件设计： 采样电阻选择低温漂、低感应的合金电阻（如锰铜）。 运放电路布局尽量靠近采样电阻，采用差分走线，避免噪声耦合。 ADC基准电压要稳定，可考虑使用外部基准源。
1. 软件实现： 精确配置定时器与ADC的触发同步。 在PWM中断或ADC转换完成中断中及时读取和处理数据。 务必进行偏移校准，并定期更新（温漂补偿）。 滤波参数需在实物上调试确定，兼顾噪声抑制与响应速度。
1. 调试技巧： 使用示波器观察采样电阻两端的电压波形，验证采样时机是否正确。通过监控$I_d$/$I_q$的波形，判断采样与滤波效果。

精确的电流采样是FOC算法得以实现的“眼睛”。掌握本章内容，你就为构建高性能、高可靠性的电机控制系统打下了坚实的基础。
