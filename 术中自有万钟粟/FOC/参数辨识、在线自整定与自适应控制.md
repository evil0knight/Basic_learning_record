## 引言：为何需要高级控制策略？

传统的FOC控制依赖于精确的电机参数（ 电阻$R$ 、 电感$L$ 、 反电动势常数$K_e$ ）。然而，这些参数会随温度、磁饱和、老化等因素变化，导致控制器性能下降。本章将探讨如何通过 参数辨识 、 在线自整定 和 自适应控制 ，使系统能够“认识”并“适应”电机，实现高性能、高鲁棒性的运行。

## 一、电机参数辨识

参数辨识是在控制器运行前或运行中，通过注入特定信号并测量响应，来估计电机关键参数的过程。

### 辨识代码：电阻与定子电感

以下是可独立编译的参数计算代码，不包含具体芯片的 ADC、PWM 驱动。采用**停机、锁定转子**辨识：先测电阻，再分别沿已知转子 d、q 轴施加小电压阶跃，得到 $L_d$、$L_q$。锁定位置未知时只能得到该注入方向的等效电感，不能直接命名为 $L_d$ 或 $L_q$。

1. **电阻：**直流注入后等待电流稳定，采集多组实际轴电压、电流，以 $R=\sum ui/\sum i^2$ 拟合。可以使用正、负注入以减小偏置影响，但不要采集换向瞬态。
2. **电感：**电流变化期间满足 $u=Ri+L\,di/dt$。对相邻采样区间积分，令 $x_k=i_{k+1}-i_k$、$y_k=\int(u-Ri)dt$，用 $L=\sum x_ky_k/\sum x_k^2$ 拟合，积分采用梯形法。
3. 电压必须是与电流同轴、同时段的实际平均电压（或根据母线电压和占空比重建并补偿死区、器件压降后的值），不能直接拿未经限幅的 PI 指令代替。电阻单位为 Ω，电感为 H，周期为 s。

```c
/******************************************************************************
 * Copyright (C) 2026 XXXXXXXXXXX, Inc.(Gmbh) or its affiliates.
 * All Rights Reserved.
 * @file parameter_identification.c
 * @par dependencies
 * - math.h
 * - stddef.h
 * - stdint.h
 * @author YA
 * @brief 锁定转子的电阻、轴电感辨识计算示例。
 * Processing flow: 采集稳态数据求 R，再采集阶跃瞬态求 Ld/Lq。
 * @version V1.0
 * @note 1 tab == 4 spaces!
 *****************************************************************************/
#include <math.h>
#include <stddef.h>
#include <stdint.h>

typedef enum
{
    IDENT_OK = 0,
    IDENT_ERR_PARAM,
    IDENT_ERR_EXCITATION,
    IDENT_ERR_RESULT
} ident_status_t;

/**
 * @brief 使用稳态数据拟合轴电阻，调用前必须确认电流已稳定。
 * @param[in] p_f_u 实际轴电压数组，V。
 * @param[in] p_f_i 同步轴电流数组，A。
 * @param[in] u32_count 样本数量。
 * @param[in] f_min_rms 最小有效电流 RMS，A，按采样噪声设置。
 * @param[out] p_f_r 电阻结果，Ω；失败时保持原值。
 * @return ident_status_t 辨识状态。
 */
ident_status_t ident_resistance(const float *p_f_u,
                               const float *p_f_i,
                               uint32_t u32_count,
                               float f_min_rms, float *p_f_r)
{
    double d_ui = 0.0;
    double d_ii = 0.0;
    double d_r;
    uint32_t u32_k;

    if ((NULL == p_f_u) || (NULL == p_f_i) || (NULL == p_f_r)
        || (2U > u32_count) || !isfinite(f_min_rms)
        || (0.0f >= f_min_rms))
    {
        return IDENT_ERR_PARAM;
    }
    for (u32_k = 0U; u32_k < u32_count; ++u32_k)
    {
        if (!isfinite(p_f_u[u32_k]) || !isfinite(p_f_i[u32_k]))
        {
            return IDENT_ERR_PARAM;
        }
        d_ui += (double)p_f_u[u32_k] * p_f_i[u32_k];
        d_ii += (double)p_f_i[u32_k] * p_f_i[u32_k];
    }
    if (d_ii < (double)u32_count * f_min_rms * f_min_rms)
    {
        return IDENT_ERR_EXCITATION;
    }
    d_r = d_ui / d_ii;
    if (!isfinite(d_r) || (0.0 >= d_r) || !isfinite((float)d_r))
    {
        return IDENT_ERR_RESULT;
    }
    *p_f_r = (float)d_r;
    return IDENT_OK;
}

/**
 * @brief 用均匀采样的阶跃瞬态拟合轴电感，输入已辨识的电阻。
 * @param[in] p_f_u 实际轴电压数组，V；不可跨电压跳变积分。
 * @param[in] p_f_i 同步轴电流数组，A。
 * @param[in] u32_count 样本数量，至少两个。
 * @param[in] f_ts 采样周期，s。
 * @param[in] f_r 电阻，Ω。
 * @param[in] f_min_di 最小有效相邻电流变化 RMS，A。
 * @param[out] p_f_l 轴电感，H；失败时保持原值。
 * @return ident_status_t 辨识状态。
 */
ident_status_t ident_inductance(const float *p_f_u,
                               const float *p_f_i,
                               uint32_t u32_count, float f_ts,
                               float f_r, float f_min_di, float *p_f_l)
{
    double d_xy = 0.0;
    double d_xx = 0.0;
    double d_x;
    double d_y;
    double d_l;
    uint32_t u32_k;

    if ((NULL == p_f_u) || (NULL == p_f_i) || (NULL == p_f_l)
        || (2U > u32_count) || !isfinite(f_ts) || (0.0f >= f_ts)
        || !isfinite(f_r) || (0.0f >= f_r)
        || !isfinite(f_min_di) || (0.0f >= f_min_di))
    {
        return IDENT_ERR_PARAM;
    }
    for (u32_k = 0U; u32_k < u32_count; ++u32_k)
    {
        if (!isfinite(p_f_u[u32_k]) || !isfinite(p_f_i[u32_k]))
        {
            return IDENT_ERR_PARAM;
        }
    }
    for (u32_k = 0U; u32_k < (u32_count - 1U); ++u32_k)
    {
        d_x = (double)p_f_i[u32_k + 1U] - p_f_i[u32_k];
        d_y = 0.5 * f_ts * ((double)p_f_u[u32_k]
              + p_f_u[u32_k + 1U] - (double)f_r
              * ((double)p_f_i[u32_k] + p_f_i[u32_k + 1U]));
        d_xy += d_x * d_y;
        d_xx += d_x * d_x;
    }
    if (d_xx < (double)(u32_count - 1U) * f_min_di * f_min_di)
    {
        return IDENT_ERR_EXCITATION;
    }
    d_l = d_xy / d_xx;
    if (!isfinite(d_l) || (0.0 >= d_l) || !isfinite((float)d_l))
    {
        return IDENT_ERR_RESULT;
    }
    *p_f_l = (float)d_l;
    return IDENT_OK;
}
```

**与 PWM 中断对接：**暂时关闭速度环和电流 PI 对测试电压的覆盖，保持锁定转子的电角度；把测试轴电压送入反 Park → SVPWM，在固定采样时刻记录同步轴电流和实际电压。施加阶跃后从第一个完整电压平台区间开始采集，不跨越跳变沿积分；采样周期应明显小于 $L/R$。采集结束后在主循环调用上述函数，避免在中断内遍历整段数组。

先用稳态数组调用 `ident_resistance()` 得到 $R$；再用 d 轴瞬态数组调用 `ident_inductance()` 得到 $L_d$，用 q 轴瞬态数组再次调用得到 $L_q$。测试过程中限制电压、电流和持续时间，尤其 q 轴注入会产生转矩，需可靠机械锁定；超限时立即停止注入。辨识电感对应当前电流工作点，磁饱和时可能随电流变化。




### 1.1 定子电阻 (R) 辨识

原理： 向定子绕组注入一个小的直流电压，测量稳态电流。根据欧姆定律 $R = \frac{V}{I}$。
**步骤：**

1. 将转子锁定在固定位置（防止转动）。
2. 在D轴（或一相）施加一个小的恒定电压 $V_{\text{test}}$。
3. 等待电流达到稳态 $I_{\text{ss}}$。
4. 计算： $R = \frac{V_{\text{test}}}{I_{\text{ss}}}$。



### 1.2 定子电感 (Ld, Lq) 与反电动势常数 (Ke) 辨识

通常采用高频信号注入或阶跃响应法。

| 参数                         | 辨识方法         | 关键公式/原理                                                                         | 备注                   |
| ---------------------------- | ---------------- | ------------------------------------------------------------------------------------- | ---------------------- |
| D/Q轴电感 ($L_d$, $L_q$) | 高频正弦电压注入 | $Z = \frac{V_{\text{ac}}}{I_{\text{ac}}}$， $L = \frac{\sqrt{Z^2 - R^2}}{2\pi f}$ | 需在多个位置测试以平均 |
| 反电动势常数 ($K_e$)       | 空载反拖法       | $K_e = \frac{V_{\text{peak}}}{\omega}$， 其中$\omega$为电角速度                   | 需外部驱动电机至匀速   |
| 转动惯量 ($J$)             | 加减速测试       | $J = \frac{\Delta T}{d\omega/dt}$                                                   | 需要转矩观测或已知转矩 |

## 二、在线参数自整定

在系统运行过程中，持续或周期性地微调控制器参数（如PI调节器的$K_p$, $K_i$），以应对参数漂移和负载变化。

### 2.1 基于模型参考自适应 (MRAS)

使用一个可调模型和一个参考模型，通过调整可调模型的参数，使其输出与参考模型一致。

- 参考模型： 代表理想系统行为。
- 可调模型： 包含待整定参数。
- 自适应律： 根据误差调整参数的算法（如梯度法）。

### 2.2 基于极值搜索 (ES)

将系统性能指标（如速度误差积分）作为成本函数，通过扰动参数并观察成本函数的变化，自动寻优到最佳参数点。

- 适用于非线性、模型不确定的系统。
- 无需精确的数学模型。
- 收敛速度相对较慢。

### 2.3 在线PI整定规则

根据实时误差($e$)和误差变化率($\Delta e$)，应用模糊规则或查表法调整$K_p$和$K_i$。

| 误差($e$) | 误差变化($\Delta e$) | 调整$K_p$ | 调整$K_i$ |    |            |            |
| ---------------------------------------------------------------- | -- | ---------- | ---------- |
| 大                                                               | 大 | 大幅增加   | 零或很小   |
| 中                                                               | 中 | 适度增加   | 适度增加   |
| 小                                                               | 小 | 保持或微调 | 保持或微调 |

## 三、自适应控制简介

自适应控制是更高级的框架，它不仅能整定参数，还能在线调整控制器的结构或控制律，以应对未知或时变的动态特性。

### 3.1 直接自适应控制 vs. 间接自适应控制

| 类型           | 原理                                                                       | 优点                           | 缺点                         |
| -------------- | -------------------------------------------------------------------------- | ------------------------------ | ---------------------------- |
| 直接自适应控制 | 直接调整控制器参数，使系统输出跟踪期望轨迹。不显式辨识对象参数。           | 结构简单，响应快。             | 稳定性证明复杂。             |
| 间接自适应控制 | 先在线辨识对象参数，然后基于辨识结果设计或更新控制器（如计算新的PI参数）。 | 物理意义清晰，可利用先验知识。 | 需要实时参数辨识，计算量大。 |

### 3.2 在FOC中的应用框架

```c
// 自适应控制律示例 (简化梯度法更新PI参数)
void adaptive_pi_tune(float error, float delta_error, float *Kp, float *Ki) {
    // 基于误差及其变化率调整参数
    float gamma_p = 0.01f; // 学习率
    float gamma_i = 0.001f;

    // 简单的梯度下降思想 (实际中会更复杂)
    *Kp += gamma_p * error * delta_error;
    *Ki += gamma_i * fabs(error);

    // 参数限幅，防止发散
    *Kp = clamp(*Kp, 0.0f, 10.0f);
    *Ki = clamp(*Ki, 0.0f, 5.0f);
}
```
