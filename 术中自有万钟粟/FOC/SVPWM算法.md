## SVPWM算法概述

SVPWM是一种通过逆变器功率管的开关状态，合成目标电压矢量的先进调制技术。它将电机三相电压视为一个在复平面旋转的空间矢量，通过 8个基本开关矢量（6个有效矢量，2个零矢量） 的线性组合来逼近目标矢量。

上图展示了α-β坐标系下的6个有效基本电压矢量（U0~U5）及其构成的六边形，以及一个目标参考电压矢量Uref。SVPWM的目标就是通过Uref所在扇区的两个相邻基本矢量来合成它。

## 第一步：扇区判断

已知目标电压矢量在α-β轴的分量Uα和Uβ，需要判断其位于哪个60°扇区。常用方法是计算三个中间变量：

```c
// 输入：Uα, Uβ
// 输出：扇区号 Sector (1~6)

float A = Uβ;
float B = (sqrt(3)*Uα - Uβ) / 2;
float C = (-sqrt(3)*Uα - Uβ) / 2;

int N = 0;
if (A > 0) N += 1;
if (B > 0) N += 2;
if (C > 0) N += 4;

// 映射N值到扇区号
const int SectorMap[8] = {0, 2, 6, 1, 4, 3, 5, 0}; // 索引0和7未使用
int Sector = SectorMap[N];
```

判断逻辑对应关系如下表：

| 扇区 | 角度范围 | 条件 (Uα, Uβ) | N值 |
| --- | --- | --- | --- |
| I | 0° ~ 60° | Uβ>0, Uβ < √3·Uα | 3 |
| II | 60° ~ 120° | Uβ>0, Uβ > √3·|Uα| | 1 |
| III | 120° ~ 180° | Uα<0, √3·Uα < Uβ < -√3·Uα | 5 |
| IV | 180° ~ 240° | Uβ<0, Uβ > √3·Uα | 4 |
| V | 240° ~ 300° | Uβ<0, Uβ < -√3·|Uα| | 6 |
| VI | 300° ~ 360° | Uα>0, -√3·Uα < Uβ < √3·Uα | 2 |

## 第二步：矢量作用时间计算

确定扇区后，需要计算两个相邻基本矢量（例如扇区I的U0和U60）以及零矢量（U0或U7）在一个PWM周期内的作用时间T1, T2, T0。

定义：

- $T$ ：PWM周期（载波周期）
- $U_{dc}$ ：直流母线电压
- $|U_{ref}|$ ：目标电压矢量幅值
- $T_1$ ：第一个基本矢量作用时间
- $T_2$ ：第二个基本矢量作用时间
- $T_0 = T - T_1 - T_2$ ：零矢量作用时间

通过矢量合成公式，可推导出各扇区通用的中间变量X, Y, Z：

```c
// 计算中间变量
float T = PWM_PERIOD; // PWM周期
float Udc = BUS_VOLTAGE;
float K = sqrt(3) * T / Udc;

float X = K * Uβ;
float Y = K * (sqrt(3)/2 * Uα + 0.5 * Uβ);
float Z = K * (-sqrt(3)/2 * Uα + 0.5 * Uβ);

// 根据扇区分配T1, T2
switch (Sector) {
    case 1: T1 = Z; T2 = Y; break;
    case 2: T1 = Y; T2 = -X; break;
    case 3: T1 = -Z; T2 = X; break;
    case 4: T1 = -X; T2 = Z; break;
    case 5: T1 = X; T2 = -Y; break;
    case 6: T1 = -Y; T2 = -Z; break;
    default: T1 = 0; T2 = 0; break;
}

// 饱和处理：若T1+T2 > T，则等比例缩小
if ((T1 + T2) > T) {
    float factor = T / (T1 + T2);
    T1 *= factor;
    T2 *= factor;
}
T0 = T - T1 - T2;
```

## 第三步：PWM占空比生成

将计算出的T1, T2, T0分配给三相逆变器的上桥臂开关，生成对应的PWM占空比。定义三个时间变量Ta, Tb, Tc，它们对应A、B、C三相上桥臂 高电平的持续时间 。

不同扇区的分配公式不同：

| 扇区 | Ta | Tb | Tc |
| --- | --- | --- | --- |
| I | T1 + T2 + T0/2 | T2 + T0/2 | T0/2 |
| II | T1 + T0/2 | T1 + T2 + T0/2 | T0/2 |
| III | T0/2 | T1 + T2 + T0/2 | T2 + T0/2 |
| IV | T0/2 | T1 + T0/2 | T1 + T2 + T0/2 |
| V | T2 + T0/2 | T0/2 | T1 + T2 + T0/2 |
| VI | T1 + T2 + T0/2 | T0/2 | T1 + T0/2 |

最终，PWM比较寄存器的值（以中心对齐模式为例）为：

```c
// 假设计数器周期为 Period
CMPA = (Period - Ta) / 2; // A相占空比对应比较值
CMPB = (Period - Tb) / 2; // B相占空比对应比较值
CMPC = (Period - Tc) / 2; // C相占空比对应比较值
```

## 第四步：七段式与五段式调制

根据零矢量的分配方式，SVPWM有两种主要的开关序列： 七段式 和 五段式 （又称DPWM）。

### 七段式SVPWM (对称调制)

在一个周期内，开关状态变化7次，使用两个零矢量（000和111），开关序列对称，谐波特性好，电磁噪声小。

### 五段式SVPWM (非对称调制)

在一个周期内，开关状态变化5次，只使用一个零矢量，开关损耗比七段式减少约1/3，但谐波稍大。

```c
// 五段式序列示例（扇区I）
// 序列： U0(100) -> U60(110) -> U111(111) -> U60(110) -> U0(100)
// 时间：   T1/2   ->   T2     ->    T0     ->   T2     ->   T1/2
```

选择建议： 对电机噪声要求高的场合（如家电、电动汽车）选用七段式；对效率要求极高、散热受限的场合（如无人机、高速电主轴）可选用五段式。
