## RTT程序编写

1. 需要
   ```
   #include <stdio.h>
   #include <SEGGER_RTT.h>
   ```
2. 使用函数:
   ```
   SEGGER_RTT_printf(0," ")
   ```

### RTT的printf重定向

> 📎 详见 [printf 重定向笔记](../../嵌软高手/printf重定向.md)

1. 打开 [microlib](../../嵌软高手/microlib打开原因.md)
2. 在 `usart.c` 里：

   ```c
   /* USER CODE BEGIN 0 */
   #include "stdio.h"
   #include <SEGGER_RTT.h>
   /* USER CODE END 0 */
   ```

   ```c
   /* USER CODE BEGIN 1 */
   int fputc(int ch, FILE *f)
   {
     SEGGER_RTT_PutChar(0, ch);
     return ch;
   }
   /* USER CODE END 1 */
   ```
