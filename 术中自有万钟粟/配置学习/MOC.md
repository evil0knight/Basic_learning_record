## 配置入口

| 配置项                 | 简介                                                                            |
| ---------------------- | ------------------------------------------------------------------------------- |
| AI配置与学习           | AI工具配置与学习资源                                                            |

| Codex设置              | Codex CLI 对接 OpenAI 兼容接口配置                                              |
| MarkItDown             | 微软的文件转 Markdown 工具，主要用来把 PDF 转成 MD                              |

| registry_finder        | 删除注册表神器,要用管理员打开,然后CTROL+F搜你想删掉的就好了,在E盘里             |

| VSCode配置             | 编辑器设置、代码补全、主题字体配置                                              |
