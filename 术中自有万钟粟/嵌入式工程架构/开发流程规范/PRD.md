## 2. 产品定义与一句话定位

X10-B1 用于学员、科研工作者以及快速原型公司搭建嵌入式消费电子低功耗开发环境。

## 4. 用户问题、场景与关键任务

| 场景         | 用户任务                                                                                                                                                                                                   | 完成判据                                                                            |
| ------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------- |
| 科研人员     | • 能够有一个实验台，将传感器信息显示在屏幕<br />• 蓝牙网关上传数据                                                                                                                                       | • 测量血氧（精度、测量时间、测量范围）<br />• 血压（精度xxx、测量时间、测量范围） |
| 教育培训机构 | 1. 立芯需要学员能够很好的上手使用板子，电源有防呆和ESD性能稳定。<br />2. 所有IO引出，提高板子应用性价比。<br />3. 有急停开关，方便测试。4. 有LED方便指示一些电源区域和通信区域的运行状态（方便远程Debug)。 |                                                                                     |
| 快速原型公司 | • 有高性价比硬件<br />• 有完善SDK，能够快速做出消费电子（手表）原型 <br />• 实现项目的内容，并且做一些注入故障测试 <br />• 有明确的规格                                                                | • 成本不超过xx                                                                     |
