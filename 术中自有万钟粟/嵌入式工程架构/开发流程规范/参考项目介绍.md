## 项目背景

在煤矿、山区或海上作业平台等环境中，手机网络信号通常无法覆盖，无法通过传统的通信手段（如电话或蜂窝网络）进行人员调度和安全管理。这种情况下，作业人员的生命体征监测、位置监控、任务分配以及紧急救援成为核心需求。

**现存问题：**

1. **缺乏实时通信：**

   - 在无手机网络信号的环境中，人员之间无法保持实时联系。

   - 发生意外时，无法快速通知其他人员和指挥中心。

2. **作业人员位置监控困难：**

   - 无法知道作业人员是否处于指定的安全区域。

   - 如果人员失联，难以及时发现并定位。

   - 在网络受限区域，有些人员并不知道已经脱离队伍，长时间未提醒后走丢。

3. **安全保障不足：**

   - 缺少统一的生命体征监测手段，无法实时评估工人健康状况。

   - 无法通过设备直接发出警报或搜救指令。

为了解决这些问题，需要设计一款专为受限网络环境打造的智能手环设备，集成蓝牙 Mesh 通信、生命体征监测、位置追踪和警报功能，以确保作业人员的安全，并提高工作效率。

## UI界面设计与功能分布

**根据需求划分功能，设计 7 个 UI 界面：**

1. **主界面：**

   - 显示当前时间、电池状态、蓝牙 Mesh 组网状态（在线/失联）。

   - 提供状态图标（如信号强度、围栏状态）。

   - 显示各个组网内成员的相对位置

2. **血氧监测界面：**

   - 显示实时血氧曲线。

   - 显示当前血氧百分比。

3. **电子围栏状态界面：**

   - 显示当前位置是否处于安全区域。

   - 如果超出围栏范围，显示警告信息和图标。

4. **NFC打卡界面：**

   - 提示将 NFC 卡靠近手环，完成考勤打卡。

   - 显示成功/失败后的反馈信息。

5. **二维码组网界面：**

   - 动态生成二维码，供管理员扫描完成组网配置。

   - 提示组网状态（如成功/失败）。

6. **Mesh消息显示界面：**

   - 实时显示 Mesh 网络中接收到的消息（如调度指令、警报信息）。

   - 支持查看最近的历史消息。

7. **失联提醒界面：**

   - 显示失联节点的编号或名称，并提供简单的定位提示。

   - 触发喇叭播放警报音效，提醒其他人协助寻找。

## 技术资源需求

1. **主控芯片：STM32F411 和 Nordic nRF52840 的分工**

   - **STM32F411：**

     - 负责 UI 驱动（如曲线绘制、二维码生成、消息显示）。

     - 控制喇叭音效播放（通过 PWM 或 DAC 输出）。

   - **Nordic nRF52840：**

     - 实现蓝牙 Mesh 通信、RSSI 信号强度分析和失联节点检测。

     - 内置 NFC，用于考勤打卡功能。

2. **外围模块**

   - **屏幕：240x280 分辨率（RGB565） SPI 接口彩屏（ST7789 ）。**

   - **喇叭：小型低功耗喇叭，用于警报音效。**

   - **传感器：集成 PPG 传感器（如 MAX30102）用于血氧监测。**

3. **功耗优化**

   - 使用 nRF52840 的低功耗 BLE Mesh 模式，减少待机时的能耗。

   - STM32F411 进入深度休眠模式时，仅保持必要外设运行。

## 功能优势与适配性

- **失联提醒：基于 Mesh 网络动态检测节点状态，实时广播警报，弥补传统蜂窝网络无法覆盖的通信盲区。**

- **电子围栏功能：确保工人处于安全区域，避免进入高风险区域。**

- **生命体征监测：实时采集并显示血氧数据，结合 Mesh 网络上传到管理端，便于健康监控。**

- **低功耗与高可靠性：通过 STM32F411 和 nRF52840 的高效分工，满足工业环境对续航和通信稳定性的要求。**

此设计能够全面适应矿区、山区或海上作业平台等受限网络环境，为作业人员提供可靠的安全保障和通信手段。
