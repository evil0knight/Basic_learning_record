# 编译文件

[← 返回 编译链接下载](./MOC.md) | [← 主页](../../index.md)

---

嵌入式开发里，Keil/IAR 编译完会生成一堆文件。四种最常见的：**AXF、ELF、HEX、BIN**。

---

## 1. AXF 和 ELF 有什么区别？

**本质上是一个东西。** AXF 就是 ARM 魔改过的 ELF，文件结构一模一样：ELF Header + Program Header Table + Sections + Section Header Table。

区别只有两个：

- **AXF 是 ARM 工具链专属**（Keil MDK 的 `armlink` 链接器产出），ELF 是跨平台的通用格式（GCC 的 `ld` 产出）。
- **AXF 在 ELF 基础上加了 ARM 特有的调试信息**（比如 CoreSight 调试寄存器配置、ARM 特有的 `.ARM.attributes` section）。所以 AXF 可以直接拖进 Keil Debug 仿真，而 GCC 生成的 ELF 需要转换。

> 平常说的 "ELF 文件" 在 ARM 嵌入式语境下，一般指 GCC 编译出的 `.elf`；"AXF" 专指 Keil 出的那个。**从文件格式角度看，AXF 就是一种 ELF。**

---

## 2. AXF 文件包含了什么内容？

AXF 是个大杂烩，链接器把编译后所有信息塞在一起：

| 内容                   | 说明                                                                |
| ---------------------- | ------------------------------------------------------------------- |
| **机器码**       | 最终烧进 Flash 的指令（`.text` 段）。                             |
| **数据段初值**   | 全局变量、static 变量的初始值（`.data`、`.rodata` 段）。        |
| **符号表**       | 每个函数、全局变量的地址信息，调试器靠它显示函数名和变量名。        |
| **调试信息**     | 源代码行号映射、变量类型、作用域，让 Keil Debug 能单步跟踪 C 代码。 |
| **段布局信息**   | 哪个段放 Flash 哪个段放 RAM、入口点在哪、栈和堆的初始地址。         |
| **反汇编信息**   | 机器码和汇编指令的对应关系（部分格式包含）。                        |
| **ARM 特有属性** | 架构版本（ARMv6M / v7M / v8M）、FPU 是否开启等。                    |

> 简单说：AXF = HEX/BIN 的机器码 + 符号表 + 调试信息 + 内存布局。**是除代码外还加了全套元数据的综合文件。**

---

## 3. 有了 AXF 是否可以生成 HEX 和 BIN？

**可以。** 只要有了 AXF，HEX 和 BIN 都能从它导出。

AXF 里已经包含了全部机器码和段地址信息，HEX/BIN 只是把这些信息用不同格式"另存"出去：

```
AXF → fromelf --bin -o output.bin --m32combined
AXF → fromelf --i32 -o output.hex --m32combined
AXF → fromelf --m32 -o output.hex
```

| 目标格式 | Keil 工具                        | GNU 工具                                        |
| -------- | -------------------------------- | ----------------------------------------------- |
| AXF→BIN | `fromelf --bin -o out.bin axf` | `arm-none-eabi-objcopy -O binary elf out.bin` |
| AXF→HEX | `fromelf --i32 -o out.hex axf` | `arm-none-eabi-objcopy -O ihex elf out.hex`   |

**反过来不行**：HEX/BIN 里没有符号表和调试信息，不能还原回 AXF/ELF。

> 这就是为什么调试器要 AXF/ELF 而不是 HEX/BIN——没符号表，调试器只能给你看汇编，不会告诉你变量名和函数走到了第几行。
