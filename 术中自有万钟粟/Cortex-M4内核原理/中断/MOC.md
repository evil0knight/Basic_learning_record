## 中断分类

| 分类维度 | 类型                         | 说明                                                   |
| -------- | ---------------------------- | ------------------------------------------------------ |
| 触发来源 | **内部中断**           | 处理器内部事件触发（定时器溢出、串口接收缓冲区非空等） |
|          | **外部中断**           | 外部事件触发（按键等）                                 |
| 可屏蔽性 | **可屏蔽中断**         | 程序可控屏蔽                                           |
|          | **不可屏蔽中断 (NMI)** | 不能屏蔽（掉电等）                                     |
