## ABI / AAPCS / 调用规约

**ABI（Application Binary Interface，应用二进制接口）**：规定二进制层面"怎么互相调用"——参数怎么传、哪些寄存器谁保存、如何返回等。

**AAPCS（ARM Architecture Procedure Call Standard）**：ARM 的函数调用标准。对 Cortex-M4（STM32F411）而言，关键点：

**参数传递**：前 4 个参数用 R0~R3；第 5 个及以后走栈上传参（低地址先入）。

**返回值**：R0（整数/指针）；启用 FPU 时，浮点可用 S0。

**寄存器保存约定**：

| 类型       | 寄存器                      | 规则                                  |
| ---------- | --------------------------- | ------------------------------------- |
| 调用者保存 | R0~R3、R12、LR（在调用点）  | 调用前自己备份，用完自己恢复          |
| 被调者保存 | R4 ~  R11（及 S16 ~ S31） | 被调函数若使用，必须在函数内 PUSH/POP |

**对齐要求**：函数入口要求 SP % 8 == 0，编译器会在序言/返场自动对齐（`SUB/ADD SP, #4/#8`）。

## 栈模型（Cortex-M 的"满递减栈"）

**Full-Descending（满减栈）**：

### 什么是满减栈？

**满**：栈指针 SP 永远指向有数据的栈地址。你不先移动指针就开始向栈里写数据，就会把之前的栈数据破坏掉。

对应的概念是**空减栈**：SP 永远指向没有数据的栈地址，所以可以直接先写入数据，再移动指针。

**减**：SP 指针向地址变小的方向移动，比如从 `0x20001234` → `0x20001230`。对应的是**增**——地址由小到大移动（`0x20001230` → `0x20001234`）。

**指令体现**：

| 操作 | 指令                | 等价长写法           | 含义     |
| ---- | ------------------- | -------------------- | -------- |
| 压栈 | `PUSH {R4-R7,LR}` | `STMDB SP!, {...}` | 先减后写 |
| 出栈 | `POP {R4-R7,PC}`  | `LDMIA SP!, {...}` | 先读后加 |

## 叶子函数 vs 非叶子函数

| 类型                 | 特征                                                             |
| -------------------- | ---------------------------------------------------------------- |
| **叶子函数**   | 内部不再调用其它函数。不必保存 LR，不一定需要建立栈帧            |
| **非叶子函数** | 内部会调用其它函数。通常需要保存 LR，用到 R4~R11 时必须 PUSH/POP |

## 函数"序言/返场"（Prologue/Epilogue）

- **序言**：进入函数时建立栈帧（`PUSH` / `SUB SP, #N` / 对齐）
- **返场**：退出函数时销毁栈帧（`ADD SP, #N` / `POP {..., PC}` 或 `POP {..., LR}` + `BX LR`）

有时会看到帧指针：

```asm
PUSH {R7, LR}
ADD  R7, SP, #0      ; 把 R7 当 frame pointer
```

## 与函数调用压栈强相关的指令

### 调用 / 返回 / 跳转

| 指令                         | 作用                                        |
| ---------------------------- | ------------------------------------------- |
| `BL func`                  | 调用已知函数（会写 LR）                     |
| `BLX Rm`                   | 调用函数指针（寄存器里有目标地址，会写 LR） |
| `BX LR`                    | 返回到调用者                                |
| `BX Rm`                    | 跳到寄存器地址（尾调用/函数指针）           |
| `B label` / `B.W label`  | 无条件分支（不写 LR）                       |
| `BEQ/BNE/BCC/BCS/...`      | 条件分支                                    |
| `CBZ Rn, label` / `CBNZ` | 零比较跳转                                  |

### 栈帧建立 / 销毁（满递减栈）

**建栈帧（序言）**：

```asm
PUSH {LR}              ; 保存返回地址
PUSH {R4-R7, LR}       ; 保存 callee-saved 寄存器 + 返回地址
SUB  SP, SP, #N        ; 为局部变量/对齐分配栈空间
```

**销栈帧（返场）**：

```asm
ADD  SP, SP, #N        ; 回收局部变量空间
POP  {..., PC}         ; 弹出并返回
; 或
POP  {..., LR}
BX   LR
```

### 参数传递 / 访问

- 前 4 个参数：R0~R3
- 第 5 个及以后：栈上传参（调用点先把值写到 `[SP, #...]`）
- 常见序列：`STR Rn, [SP, #imm]` 或一次性 `PUSH {...}`
- 被调函数通过基于 SP 的 `LDR` 取第 5/6 个参数
- 返回值：R0（整数/指针）；浮点可走 S0（启用 FPU 时）

### 数据搬运 / 局部变量

- `MOV/MOVS`、`ADD/SUB`、`LSL/LSR/ASR` 等
- `LDR/STR`（字/半字/字节变体：`LDRH/STRH`、`LDRB/STRB`）
- 加载常量/地址：
  - `ADR Rd, label`：取相对 PC 的地址
  - `LDR Rd, =imm`：伪指令，生成常量池，再用一次 LDR 取常量
  - `MOVW/MOVT`：把 32 位常量拆成低/高 16 位装入寄存器

### 对齐与占位

- `NOP`：常用于对齐/延时/占位
- `IT/ITE`：条件块（ARMv7-M 可用，编译器在 `-O0` 偶尔会发）
