# 创建文件

> 描述:创建文件的时候遵守下面workflow:

1. 把文件名称放到第一行,前面加一个"# ",做成一级标题
2. 加"[←MOC]()"括号内填写最短相对路径,用于返回上一级目录
   加一个"|"(用来分割)写一个"[←主页]()"括号内填写文件到index.md的最短相对路径,用于跳转主页
   如果文件被其他的文件索引到(也就是其他文件通过点击索引进入本文件),还需要再回车,
   然后添加"[←返回xxxx]()"括号内填写文件到那个文件的最短相对路径,用于跳转
3. 加一行回车再加"---"再加回车,写出一个分割线
4. 在所属 MOC 中添加新文件入口;新建学科、技术分类或模块时,同步更新「书」「术」「库」对应的总 MOC。
5. 检查导航和 MOC 入口的目标是否存在,路径大小写是否一致,确认新文件能从 MOC 进入并返回。

## rules:

- 只负责文件位置、名称、标题、导航、分割线和 MOC 入口;正文由“填写文件内容”规则处理。
- 创建前先查看相关目录和 MOC,已有同主题笔记时优先复用,不重复创建或覆盖已有文件。
- 文件名和目录名不含中英文括号,Markdown 扩展名使用小写 `.md`,链接使用 `/`。
