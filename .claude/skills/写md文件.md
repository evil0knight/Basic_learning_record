# 写 md 文件

## workflow

1. 明确本次要写的主题和范围，先按知识点搜索已有笔记，只读取相关段落；已有知识优先复用，通过下方“双向索引”连接两篇笔记，不重复抄写。
2. 按内容需要划分章节：概念写清含义和机制，操作写清前提和步骤，对比使用表格；不为凑结构添加无用章节。
3. 保留已有文件标题、导航和分割线，从正文开始编写；章节使用 `##`，子章节使用 `###`，不要再加一级标题。
4. 需要时补充示例、代码、图片或公式，放在对应说明附近；链接和图片路径相对于当前文件计算。
5. 写完检查事实、前后逻辑、重复内容、Markdown 格式及本地链接目标，确认复用笔记的双向链接完整且不重复，删除空标题和未填写的占位内容。

## 知识复用与双向索引

1. 确认已有笔记讲的是同一知识点且适用于当前场景，不能只凭名称相同就复用。当前笔记只写必要衔接和本场景的差异，详细知识链接到已有笔记或对应章节。
2. 在当前笔记涉及该知识的位置添加 `[知识点名称](被复用笔记的相对路径.md)`；需要定位章节时追加有效的 `#锚点`。
3. 在被复用笔记的标题下，保留原有导航，在导航链接下方另起一行添加 `[← 返回当前笔记标题](当前笔记的相对路径.md)`，放在正文分割线之前；已有相同返回链接时不重复添加。
4. 两个方向的相对路径分别从各自文件所在目录计算，不能直接照抄；保留其他笔记已有的返回链接。

被复用笔记的顶部示例：

```markdown
# 被复用笔记标题
[← MOC](./MOC.md) | [← 主页](../../index.md)
[← 返回当前笔记标题](../某目录/当前笔记.md)|

---
```

示例路径按实际位置填写；原有导航是表格时，将返回链接放在表格下方。

## rules

- 直接切入主题，信息密度最大化；保留必要的因果、条件和步骤，不为精简牺牲准确性。
- 列表用于线性流程、层级拆解，以及将非结构化的长文本说明拆成要点；有先后顺序用有序列表，并列事项用无序列表。
- 表格用于多变量对比、属性高度统一的条目和矩阵式映射；同类属性放在同一列，便于横向比较。
- 避免产出无效 AI 垃圾：不写寒暄、空泛套话、无关背景、重复解释、凑数章节或结尾说教；每条内容都应提供具体信息，不把同一内容换句话反复写。
- 正文最后不要加"**一句话总结**"、"**本章小结**"等收尾章节；修改旧笔记时顺手删除已有的这类章节。
- 代码块标注实际语言；可复制示例包含必要声明和依赖说明，省略实现时明确标为片段或伪代码。
- 图片配简短说明，链接使用 `/`，Markdown 目标扩展名使用小写 `.md`，路径大小写与实际文件一致。
- 行内公式用 `$...$`，块级公式用 `$$...$$`；不使用 `**\mathbf{...}**` 代替公式。
- 标题、段落、列表和代码块之间留空行；不使用 `style="display:inline"`。
- 不编造参数、来源或测试结果；资料不足时明确待核实，不把猜测写成确定事实。
- 本规则处理正文及知识复用所需的双向索引，不移动文件或修改 MOC 入口；正文标题变化时同步修复受影响的锚点链接。
