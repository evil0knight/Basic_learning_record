# 音频转写

## 什么时候用

1. 已确认取不到字幕：`/x/player/wbi/v2` 返回空 `subtitles`、B站 AI 总结也是空。
2. 手上有本地音视频文件要转文字。

**先走 bili-note 的字幕路线，拿不到再回来。** 字幕比转写准，也快得多。

## 依赖

- `pip install faster-whisper`（约 300MB）
- ffmpeg 在 PATH
- 首次运行会下载模型到 `~/.cache/faster-whisper`：`small` 约 500MB

## workflow

```powershell
python "D:\Basic_learning_record\.claude\scripts\transcribe.py" "音频或视频文件" --model small --language zh
```

1. 输出默认写在输入文件同目录、同名 `.txt`，每行 `[mm:ss] 文本`。
2. 输出已存在会跳过，加 `--force` 覆盖。
3. 跑完把 txt 读进来再做笔记，不要边转边写。

## 模型怎么选

| 模型 | 40 分钟音频 CPU 耗时 | 用途 |
| ---- | ---- | ---- |
| base | 约 8 分钟 | 只要听懂大意 |
| small | 约 20 分钟 | 默认，够做笔记 |
| medium | 约 1 小时 | 术语多、口音重 |

## rules

- 不走 `model.transcribe(path)`。它依赖 av 解码，av 版本一变就报 `TypeError: open() got an unexpected keyword argument 'metadata_errors'`。脚本已改成 ffmpeg 转 16k WAV 再读成 numpy 数组，绕开 av。
- 已关闭 `condition_on_previous_text`。长音频开着它会出现整段重复幻觉，输出里看到同一句话循环就是它。
- 输出常是繁体，且专有名词会错。写笔记时按上下文校正，不确定的数字不要写成事实，放进未知清单。
- 转写文本只用于提取，不要整段抄进笔记。
